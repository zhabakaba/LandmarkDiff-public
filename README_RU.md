# LandmarkDiff — интерфейс «до/после» (TPS, CPU)

Русскоязычное веб-приложение для визуализации изменений после косметических
процедур: загрузка фотографии, выбор процедуры, настройка интенсивности и
сравнение «до/после».

> **Текущее состояние работы** (что сделано, замеры, что дальше) —
> [`PROGRESS_RU.md`](PROGRESS_RU.md). Начинать продолжение с него.

> **Важно.** Визуализация создана геометрическим преобразованием изображения.
> Она предназначена для обсуждения со специалистом и не является медицинским
> прогнозом или гарантией результата.

## Что это за режим

Работает **только TPS-режим на CPU**: ориентиры лица (MediaPipe, 478 точек)
смещаются пресетом процедуры, затем изображение деформируется тонкопластинчатым
сплайном. Нейросетевые режимы (`img2img`, `controlnet`, `controlnet_ip`),
ArcFace и постобработка не используются и не загружаются — это геометрическое
преобразование, а не генерация фотореалистичного результата.

## Установка (Windows, bash/PowerShell)

Нужен Python 3.10–3.12. Окружение создаётся **внутри проекта**, глобальный
Python не изменяется.

```bash
cd /path/to/LandmarkDiff-public
python -m venv .venv
.venv/Scripts/python.exe -m pip install --upgrade pip
.venv/Scripts/python.exe -m pip install -e ".[app]"
```

Linux/macOS: замените `.venv/Scripts/python.exe` на `.venv/bin/python`.

Модель MediaPipe Face Landmarker (~3.6 МБ) скачивается один раз при первом
запуске с официального домена `storage.googleapis.com` и сохраняется в
`models/face_landmarker.task`. Дальше интернет не нужен. Скачивание можно
запретить: `LANDMARKDIFF_NO_DOWNLOAD=1`.

## Как пользоваться

1. Загрузите JPG, PNG или WebP до 10 МБ (учитывается EXIF-ориентация).
2. Выберите процедуру — список формируется из фактических пресетов
   установленной версии LandmarkDiff (17 процедур, включая ринопластику,
   блефаропластику, ритидэктомию, ортогнатическую операцию, поднятие бровей,
   ментопластику).
3. Задайте интенсивность 0–100. При 0 изображение возвращается без изменений.
4. Нажмите «Сформировать результат».
5. Сравните: слайдер «до/после» (положение разделителя) или режим «два
   изображения рядом». После смены процедуры/интенсивности нажмите кнопку
   повторно, чтобы обновить результат.
6. Скачайте результат (`result.png`) или совмещённое сравнение
   (`comparison.png`).
7. «Удалить фотографию» очищает изображения и временные файлы сессии.

Отладочная панель (скрыта по умолчанию) показывает исходные и изменённые
ориентиры, маску и технические параметры запуска.

## Локальная деформация и исправленные пресеты

Результат уходит от «увеличения/уменьшения картинки» в четырёх местах
(`services/deformation.py`, код библиотеки не затронут):

- **Ограничение областью операции.** Вес каждого ориентира берётся из
  феатерованной маски процедуры (`generate_surgical_mask`), поле TPS строится
  по сдвигам `w · Δ`, а готовый результат смешивается с исходником по этой же
  маске. Раньше TPS деформировал весь кадр: на тестовом фото для гениопластики
  вне маски менялось 1647 пикселей, теперь 0 — фон, волосы и плечи остаются
  нетронутыми.
- **Направления и амплитуды.** Для менто-/гениопластики, блефаропластики,
  поднятия бровей, ортогнатики и подтяжки лица сдвиги задаются в обёртке. Библиотечные пресеты
  двигали подбородок вверх (−Y) и укорачивали нижнюю треть лица; теперь
  подбородок опускается, а амплитуды подобраны по реальным фото. На кадре
  512×512 при интенсивности 70 максимальный сдвиг — 4.4 px для ментопластики
  и 5.0 px для гениопластики (было 5.3 и 7.4). В блефаропластике нижнее веко
  подтягивается вверх, а не опускается, а сдвиг века уменьшен с 3.8 до 2.9 px,
  чтобы меньше заламывалась оправа очков.
- **Ортогнатика без перекоса.** Библиотечный пресет суммировал перекрывающиеся
  хэндлы и уводил левую сторону челюсти вверх на 10–12 px, правую — на 5–7 px.
  Теперь сдвиги симметричны, максимальный сдвиг при интенсивности 70 — 2.4 px
  (было 14.2).
- **Подтяжка лица без сжатия нижней трети.** Библиотечный пресет складывал
  12 хэндлов радиусом 40 px и поднимал всю нижнюю треть: при интенсивности 100
  максимальный сдвиг доходил до 8.4 px (на широком кадре — до 15 px), рот и
  подбородок уезжали вверх. Теперь двигаются только контур челюсти у ушей
  (до 4 px) и виски (0.6 px), а вершина подбородка и рот остаются на месте.
- **Без утроения сдвига.** Перекрывающиеся RBF-хэндлы усредняются
  (`Σ wᵢ·dᵢ / Σ wᵢ`), а не суммируются: библиотечная сумма давала сдвиг в 2–3
  раза больше заданного. Остальные 11 процедур продолжают использовать
  библиотечные пресеты — изменилось только то, что они тоже не выходят за
  свою маску.

В технических данных запуска появились поля `localized`, `inside_shift_px`,
`outside_shift_px`, `mask_fraction`; `mean_shift_px` и `max_shift_px` теперь
считаются по фактически применённым сдвигам (с учётом веса маски).

Ограничение метода: 2D-warp не отличает кожу от аксессуаров, поэтому оправа
очков, украшения и волосы внутри области операции деформируются вместе с
тканью. Это свойство геометрического подхода, а не регрессия; лечится только
сегментацией и генеративной дорисовкой (маршрут с ControlNet/img2img).

## Структура

```
app_before_after.py      точка входа (только 127.0.0.1)
ui/texts.py              русские тексты, подписи процедур
ui/layout.py             Gradio-интерфейс и обработчики
services/images.py       проверка, EXIF, подготовка изображений, сессии
services/inference.py    обёртка над LandmarkDiff (TPS/CPU), ошибки
services/deformation.py  сдвиги для 6 процедур и локальный (по маске) warp
services/export.py       PNG, слайдер-композит, side-by-side
tests/test_before_after_app.py
models/face_landmarker.task   модель MediaPipe (локально)
.sessions/               временные файлы сессий (удаляются)
.logs/app.log            технический журнал без изображений
```

Код библиотеки LandmarkDiff не изменялся — всё реализовано внешней обёрткой.

## Отключённые модули и причины

| Модуль | Причина отключения |
|---|---|
| `controlnet`, `controlnet_ip`, `img2img` | Требуют GPU и веса Stable Diffusion/ControlNet; базовая задача — TPS на CPU |
| ArcFace / InsightFace (`face_verifier`) | Предобученные веса только для non-commercial использования |
| CodeFormer / GFPGAN / Real-ESRGAN | Некоммерческие или непроверенные лицензии, постобработка не требуется |
| Обучение и дообучение модели | Не входит в задачу |
| Live-видео, многопользовательский режим, PDF-отчёт, CRM | Не входят в задачу |

## Ограничения

- Результат геометрический: свет, текстура и объём ткани не моделируются.
- Сильно повёрнутые лица (профиль) и несколько лиц не поддерживаются —
  выводится понятное сообщение об ошибке.
- Нет клинической валидации; приложение не является медицинским изделием.
- Скорость зависит от размера фото: ~1–2 с на изображение 512 px на CPU.
