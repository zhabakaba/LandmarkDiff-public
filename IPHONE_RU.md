# Продолжение работы с iPhone

Как открыть проект на телефоне и продолжить с текущего места.

## Где вы сейчас

Работа идёт в **терминальном клиенте Freebuff (CLI)**. В нём нет переключателя
`Local → Cloud` и команды `Continue in Cloud`: это функция Desktop-приложения.
В реестре команд CLI есть только `/model`, `/reasoning`, `/history`, `/export`
и другие — переноса чата в облако там нет.

Поэтому мост на телефон — GitHub-ветка `app/before-after-ru`, в которой лежит
весь код и `PROGRESS_RU.md` с состоянием работы.

## Шаг 1. На iPhone: открыть облачный проект

1. Откройте <https://freebuff.com> в Safari и войдите через тот же аккаунт
   (Google, `zhabakaba`). Проще делать это в браузере: импорт из GitHub там
   есть в любом случае.
2. В поле ввода нажмите **Select GitHub repository** (выбор репозитория).
3. Выберите:
   - репозиторий `zhabakaba/LandmarkDiff-public`;
   - ветку `app/before-after-ru`;
   - **Use repository**.
4. Откройте приложение Freebuff на iPhone под тем же аккаунтом — созданный
   облачный проект появится в **Projects**, и его можно продолжить с телефона.

## Шаг 2. Первое сообщение

В новом облачном чате напишите:

> Прочитай `PROGRESS_RU.md` и продолжи с раздела «Что дальше».

Файл лежит в корне ветки, поэтому агент сразу увидит: что сделано, замеры
до/после, ограничения и три следующих шага.

## Если позже понадобится Desktop

В Desktop-приложении (не в CLI) доступен быстрый перенос локального чата:
в поле ввода переключить **Local → Cloud** либо меню чата →
**Continue in Cloud**. Тогда копируются история и файлы проекта. Но история
чатов CLI и Desktop не общая, поэтому для текущей сессии это не сработает.

## Что важно помнить

- **Каждый облачный чат работает на своей копии.** Изменения в Cloud не
  возвращаются на компьютер автоматически.
- **Вернуть правки на ПК:** попросить облачного агента запушить ветку, затем
  локально `git pull fork app/before-after-ru`.
- **Интерфейс приложения на телефоне не запустить**: нужны Python, `.venv` и
  модель MediaPipe. Телефон — для чата, чтения кода и правок.
- **Файлы и терминал** в iOS-клиенте открываются в браузерном workspace.
