# Продолжение работы с iPhone

Как перенести текущий чат на телефон и продолжить с того же места.

## Главное

У Freebuff есть штатный перенос локального чата в Cloud:
**Continue in Cloud**. Он копирует историю чата и файлы проекта, после чего чат
продолжается в облаке и становится доступен с телефона под тем же аккаунтом.
GitHub-ветка (`app/before-after-ru`) — запасной путь и способ вернуть правки
обратно на компьютер.

## Шаг 1. На компьютере: перенести чат в Cloud

1. Дождитесь, пока агент закончит текущий ответ: перенос начинается только с
   завершённого хода.
2. В поле ввода откройте выпадающий список рядом с выбором модели, где стоит
   **Local** (локально), и переключите на **Cloud**.
   Альтернатива: меню чата в боковой панели → **Continue in Cloud**.
3. Подтвердите **Continue in Cloud**. История чата и файлы проекта копируются в
   облако, чат продолжается там.
4. Если появится ошибка «A message is too large to move to Cloud»: меню чата →
   **Retry cloud handoff**. Если не помогло — **Keep this chat local** и
   используйте путь через GitHub (ниже).

## Шаг 2. На iPhone: открыть и продолжить

1. Откройте приложение Freebuff и войдите через тот же Google-аккаунт.
2. Откройте **Projects** (проекты) и найдите проект `LandmarkDiff-public` —
   после переноса он появится в облачных проектах вместе с этим чатом.
3. Откройте чат и проверьте последние сообщения: они должны совпадать с тем,
   что было на компьютере.
4. Продолжайте обычным сообщением. Первый запрос лучше начать так:

   > Прочитай `PROGRESS_RU.md` и продолжи с раздела «Что дальше».

   Файлы проекта тоже скопированы в облако, поэтому `PROGRESS_RU.md` доступен
   агенту сразу.

## Что важно помнить

- **Снимок, а не живая синхронизация.** Правки, сделанные на компьютере после
  переноса, в облачную копию не попадают. И наоборот: изменения в Cloud не
  возвращаются на ПК автоматически.
- **Файлы и терминал на телефоне** открываются в браузерном workspace — это
  штатное поведение iOS-клиента.
- **Сам интерфейс приложения на телефоне не запустить**: нужны Python, `.venv`
  и модель MediaPipe. Телефон — для чата, чтения кода и правок.
- **Очередь сообщений.** Если отправили сообщение и сразу заблокировали
  телефон, оно может не уйти до возврата в приложение. Задачи, уже запущенные
  на сервере, продолжают работать.

## Запасной путь: GitHub

Ветка уже создана и запушена:
<https://github.com/zhabakaba/LandmarkDiff-public/tree/app/before-after-ru>

1. На телефоне: **New chat** → **Select GitHub repository** →
   `zhabakaba/LandmarkDiff-public` → ветка `app/before-after-ru` →
   **Use repository**.
2. Первое сообщение — то же: «Прочитай `PROGRESS_RU.md`…».
3. Вернуть правки на компьютер: попросить облачного агента запушить ветку,
   затем локально `git pull fork app/before-after-ru`.
